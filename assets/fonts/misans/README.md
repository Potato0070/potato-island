# MiSans · 金库界面字体

来源：小米官方网站 https://hyperos.mi.com/font-download/MiSans.zip
授权说明：https://hyperos.mi.com/font/zh/download/
使用 FAQ：https://hyperos.mi.com/font/zh/faq/

使用官方原始 MiSans-Regular.woff2 和 MiSans-Semibold.woff2，未经裁剪或字形修改。官方原始字体包归档于 E:\土豆岛资源库\字体\MiSans\MiSans_official.zip。

hooks/use-island-fonts.ts 在 Web 的金库相关页面挂载后加载字体；静态导出阶段不注册全站字体预加载。加载前、加载失败与非 Web 平台使用系统字体，不阻塞内容或操作。字体文件保留官方原样，当前仅将已确认的金库页面接入新字体，其他页面按后续确认逐页迁移。

软件字体说明随 public/font-notices.txt 一起导出。
