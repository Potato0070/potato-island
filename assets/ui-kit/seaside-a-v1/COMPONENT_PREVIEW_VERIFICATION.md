# A 海边卡册组件预览验证

日期：2026-10-18。范围为独立浏览器预览，未替换 Expo 页面，未修改数据库、真实账户或资产。

## 已完成

- 素材通过原始 WebP 的九个视口装配，依据实际可见边界处理透明边距。中心可伸展，四角按同一比例缩放；没有生成新的装饰素材。
- 默认、按下、禁用、加载、焦点、错误、筛选选中和复选框半选状态。
- 金额校验：有限正数、最多两位小数、示例最高价 300。错误保留输入；焦点为暖棕线，输入字号 16px。
- 搜索名称与完整编号、在库/寄售分类、编号及获取时间排序。抽屉使用临时选择；取消不改变列表，应用后才排序。
- 确认、模拟提交、失败留在弹窗、成功小弹窗；提交中禁用确认、取消、关闭和 Escape，按钮防重复点击。
- 材料单选、一键全选、半选、齐全确认、缺少材料、补齐入口说明。补齐入口是预览反馈，并未接入真实市场路由。
- 允许减弱动画，弹窗采用原生 dialog 焦点约束；表单和按钮有可访问标签。

## 浏览器检查

通过只读 127.0.0.1:8191 白名单服务器检查。只提供本次预览产物，没有数据库/API 写入口。浏览器工具不允许 file 协议，文件链接模式未由工具验证。

| 检查 | 观察结果 |

## 修正与限制

- 修正了初版 100vw 抽屉在桌面滚动条环境下的宽度问题；改用可用百分比宽度，并在弹窗打开时锁定背景滚动。
- 排序选项也使用本次生成的标签素材，文字与素材分离。
- 搜索和重绘时会断开旧素材的 ResizeObserver，避免重复筛选积累观察器。
- 预览没有外部字体、运行时依赖或数据库请求。预览会显示多种组件，正式页面仍应按需加载素材。
- 尚未验证 iOS/Android 原生组件、真实软键盘、真实交易响应、系统返回键和旧浏览器兼容；下一步将当前规则移植为应用组件，并逐页验证。
- 文案与字号在预览中已保持可读；对比度不能用单个采样值概括所有纹理像素，批量上线前仍需结合最终字号和实际页面检查。
