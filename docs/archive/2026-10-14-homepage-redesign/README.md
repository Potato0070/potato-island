# 土豆岛首页改版归档

归档日期：2026-10-14

本目录记录首页视觉方案的用户确认结果、实施边界和资源索引，作为 Cursor 后续迭代的稳定依据。修改前先读本目录，不得把首页确认自动解释成全站改版授权。

## 当前基线

- 用户确认的首页效果稿：`E:\土豆岛资源库\首页改版\参考稿\exec-5b820f6d-e9c9-4593-b0e4-602077965d5d.png`
- 用户确认的 Logo 方向：Logo 方案 B（戴旅行帽的岛民从小岛探出头），见设计决议。
- 项目实现位置：`app/(tabs)/index.tsx`；底部导航入口位于 `app/(tabs)/_layout.tsx`，交互实现位于 `components/LiquidGlassTabBar.tsx`。
- 项目代码仍保存在本仓库；确认稿、方案探索、对话摘要和轻量资源副本已归档到 E 盘指定目录。

## 文件

- `DESIGN_DECISIONS.md`：已经确认的视觉和交互决策。
- `CHANGE_BOUNDARIES.md`：定型项、可微调项和禁止扩大范围的约束。
- `ASSET_INDEX.md`：视觉资源及其归档目标、使用位置和状态。
- `IMPLEMENTATION_LOG.md`：本轮实施范围与验证结果。

## 修改流程

1. 用户确认的效果稿是首页视觉实现基线。
2. 在首页范围内按效果稿实施，并将头部左侧标志替换为 Logo B。
3. 改动前后保持其他页面、业务逻辑、路由和数据库行为不变。
4. 新生成的源资源按用户指示归档到 `E:\土豆岛资源库`；工作区中的应用运行资源只保留项目构建所需的轻量副本。
5. 每次完成后更新本目录的决议、边界和资源索引。

底部导航二次迭代已由用户单独确认，具体标签、图标风格和液态玻璃交互见 `DESIGN_DECISIONS.md` 的“底部导航二次确认”及对应变更记录。
