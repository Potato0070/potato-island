## 建议新增的 ImageGen 素材

### 第一批：四种通用空状态

2026-10-16 更新：用户已选择 C「绘本彩铅」，四张独立透明无字原图已生成，存放于 assets/empty-states/storybook-pencil-v1/。接入页面前仍需进行小尺寸与边缘验收。

| 素材 | 建议意象 | 复用场景 | 状态边界 |
|---|---|---|---|
| empty-inventory | 打开的木制收纳箱，内部可见，少量布衬 | 金库无藏品、暂无材料、当前系列无持有 | 文案分别表达未持有与材料不足；不是网络错误 |
| empty-mailbox | 岛上小信箱与一封素色信封 | 暂无消息、暂无订单、暂无成交记录 | 可复用底图，但标题与下一步按实际内容显示 |
| empty-search | 小放大镜与摊开的简洁地图 | 搜索无结果、筛选无匹配、暂无对应活动 | 筛选和重置入口始终可见 |
| network-unavailable | 小灯塔与被雾遮住的信号方向 | 加载失败、网络超时、服务暂不可用 | 仅表达暂时无法加载，不能显示“没有藏品”或假零值 |

共同要求：透明背景、一个完整主体、低饱和、彩铅描边、无内嵌文字、四周透明留白；手机显示宽度建议 80–112 逻辑像素，正文和操作入口仍是主体。每张在白底、暖灰与深色检查底验收。四张构成同一套，避免各自引入新的角色。

### 第二批：金库快捷入口

2026-10-16 更新：用户已选择 A「经典岛居」。订单、邀请、求购、钱包、设置的五张独立透明原图已生成，存放于 assets/treasury/classic-island-v1/；页面仍待预览与接入验收。

## 用组件统一，无需生成图片的部分

| 部分 | 处理方式 |
|---|---|
| 返回、关闭、箭头、搜索、清空、复制、筛选、排序 | 统一矢量图标族，18–24 逻辑像素，线条粗细与光学大小一致 |
| 关注爱心 | 保留现有爱心和已选/未选状态 |
| 复选框、全选、单选、数量加减 | 代码控件；热区至少 44 × 44，图形可更小 |
| 材料选择抽屉 | 白色面板、细边、抓手、关闭键、已选数与固定确认区；无需整幅背景图片 |
| 交易确认弹窗 | 真实藏品缩略图、对象/数量/金额/费用与明确按钮；无需重复生成商品插画 |
| 完成弹窗 | 真实目标藏品图加轻量完成标记，文案与下一步独立显示 |
| 成功、失败、警告、信息小标记 | 统一矢量符号；不能只靠颜色区分结果 |
| 加载、进度、倒计时、骨架 | 由代码绘制和动画；禁用/加载不依赖额外图片 |
| 选中态、胶囊分类、排序控件、状态标签 | 代码令牌控制颜色、描边和状态，避免每个文字都生成一张图 |
| 输入焦点与表单报错 | 统一中性描边、错误提示与键盘处理；不依赖贴图 |

## 资源交付与归档

1. 预览 → 选定 → 独立透明图 → 透明边缘与实际尺寸检查 → 页面效果验收 → 接入。
2. 原始素材、提示词、选择记录与规格归档到 E:\土豆岛资源库；仓库仅保留运行所需的轻量文件。
3. 同一系列统一命名、光学大小、边缘留白和色彩；不得直接把方案拼图作为运行时素材。
4. 页面不能把素材背景当作整块点击热区的尺寸依据；布局负责热区、图片负责装饰。
5. 本轮建议新增优先为四张通用空态；接着是五个金库图标。字体应加载真实字体文件后再提供字形预览，不把 ImageGen 生成的文字当作字体样本。
