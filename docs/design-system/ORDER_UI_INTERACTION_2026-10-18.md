# 求购、竞价、加价与撤单 UI：本地验收

本文记录发布前的本地验收。本批是前端界面和交互调整。数据库表、RLS、RPC 和业务定价规则没有迁移或修改。测试使用纯虚构账户和本机假接口，没有执行真实交易。

## 页面与流程

| 场景 | 展示与交互 | 完成后的去向 |
| --- | --- | --- |
| 发起求购／竞价 | 独立页面展示目标藏品、单价范围、数量、预计冻结金额、可用余额、Potato卡数量 | 核对弹窗 → 结果弹窗 → 订单管理 |
| 选择藏品 | 底部抽屉，可按名称搜索；更换系列清空旧单价并重新读取范围 | 留在发起页面 |
| 输入错误 | 框下说明具体原因；禁止空数量、负数、多于两位小数、无穷值和超出可安全计算范围的金额 | 保留输入供修改 |
| 余额不足 | 明确显示余额和提示，停止进入确认 | 调整单价或数量 |
| Potato卡不足 | 显示当前数量与“去集市补齐”入口，核对时说明需要 1 张在库卡 | 前往集市 |
| 调整出价 | 底部抽屉显示当前单价、需求数量、新单价、补充冻结差额和余额 | 核对加价弹窗 → 结果弹窗 → 原订单标签 |
| 撤回订单 | 小弹窗展示藏品、预计解冻金额与后果；保留订单和确认撤单两项操作 | 结果弹窗后留在订单管理 |
| 撤回寄售 | 小弹窗确认后处理 | 结果弹窗后留在订单管理 |
| 未登录 | 发起页引导登录；订单页显示登录入口，不无限加载 | 登录页面 |
| 读取失败 | 显示错误和重试，区别于空列表 | 原页面重试 |
| 结果不确定 | 保留确认内容和金额，说明需核对订单／余额；阻止当前页面重复写入 | 发起页提供查看订单入口，订单页可返回金库核对 |

“返回修改”保留已填写内容。处理中的确认和取消不可点击，使用 ref 锁阻止同一页面重复提交。订单标签重复点击不重新触发加载状态；切换标签的过期读取结果不会覆盖新标签。

## 视觉、素材与资源

- 复用已确认 A 系列海边卡册素材：米白纸面、蓝色边线、金色交易按钮、陶土色撤回按钮。没有新增 IP 或未经确认的新视觉素材。
- 使用共用 Seaside 按钮、输入框、抽屉、确认与结果组件。边角按九块视口显示原图，中间纸纹适应内容高度；不把整张预览图作为可交互页面背景。
- 按钮高度至少 56；窄屏操作自动纵排。输入文字 16px，浏览器默认蓝色 outline 关闭，保留暖棕色焦点提示。
- 订单空态使用现有手绘空金库素材；藏品封面失败使用明确占位，不访问第三方占位图服务。
- 关闭抽屉／确认／结果时立即移除内容，避免状态清空后短暂闪现空标题或 0 金额；打开保留轻量系统淡入。抽屉沿用系统滑入。
- 订单用 FlatList；仅打开的确认／结果挂载素材，不引入动画库或新字体包。本次首页脚本 gzip 为 522,247 字节，36 页导出检查通过。
