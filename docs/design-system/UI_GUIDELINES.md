# 土豆岛 UI 与交互规范

版本：1.0
建立日期：2026-10-14
适用范围：后续移动端页面设计、预览和实现；页面专属颜色与结构须先经用户确认。

## 设计原则

- 页面以白色为主底色，信息层级清楚，操作入口可辨认；用留白组织内容，不用装饰元素填满空处。
- 延续岛民图鉴的手绘彩铅和轻水粉气质，使用低饱和的岛屿自然色；商品图和真实数据优先于装饰。
- 页面先做预览，用户确认后再修改产品代码。只把获准的页面视觉应用到对应页面，不推断为全站换肤。
- 每个控件说明一个功能；同一行里主分类比排序筛选更醒目，说明信息比操作按钮更轻。
- 预览生成的示例数据不得作为真实商品名、价格、成交数或库存写入产品。

## 字体层级

尺寸采用 React Native 逻辑像素（sp）。2026-10-16 字体方案更新：金库 Web 页面统一使用官方 MiSans Regular / Semibold，通过共享 useIslandFonts 加载，加载前以系统字体显示内容。其他页面待逐页确认后迁移，不为各页面再选不同字体。字体来源与说明随 public/font-notices.txt、public/misans-license.pdf 发布。

| 角色 | 字号 / 行高 | 字重 | 用途 |
|---|---:|---|---|
| 页面标题 | 22 / 28 | 700–800 | 顶部居中页面名，如“交易集市” |
| 区块标题 | 18 / 24 | 700 | 页面内主要内容分组 |
| 卡片标题 | 15 / 20 | 600–700 | 藏品或内容名称 |
| 正文与主要控件 | 14 / 20 | 400–600 | 搜索提示、分类名称、说明 |
| 价格与关键数值 | 18 / 24 | 700 | 价格、余额等主要数字；与币种或单位同组 |
| 次级筛选 | 12 / 16 | 500–600 | “最热、最新、价格排序、关注”等轻量选项 |
| 辅助信息 | 11 / 14 | 400–500 | 在售量、时间、状态和底栏标签 |

11 sp 是普通界面文字的最小值。只有密集的非核心辅助信息可使用 10 sp，并须验证手机实机可读性。一个页面最多使用四个常规字号层级，特殊数值可以独立突出。

## 间距与布局

- 间距使用 4 的倍数：4、8、12、16、20、24。避免页面里出现无意义的任意间距值。
- 手机页面左右内容边距通常为 16；内容区块垂直间距通常为 16 或 24。
- 双列藏品网格使用等宽列和 12 间距；藏品图固定 1:1，图片不拉伸。横向分类可滚动，不压缩文字。
- 次级页面标题居中显示页面名称，不重复放置品牌 Logo 与“土豆岛”字样。
- 底部内容为导航栏与安全区留出空间，列表末项不能被导航栏遮挡。

## 控件规格

| 控件 | 视觉规格 | 交互要求 |
|---|---|---|
| 搜索框 | 高 44–46，圆角 12–14，白或暖白底，暖浅灰描边 | 提示文案必须和实际搜索字段一致；保留键盘搜索行为 |
| 手机网页搜索输入 | 字号至少 16；展开态占满当前内容行 | 避免移动浏览器聚焦时自动缩放；焦点使用暖色光标与中性描边 |
| 主分类 chip | 最小高 40，水平内边距 16 左右，圆角 12–14 | 选中态清楚；分类来源和顺序沿用后台动态数据 |
| 次级排序 | 高至少 42，字号 11–12；当前项使用浅雾霾蓝状态 | 视觉上弱于主分区；与主分区保持同一行，极窄屏压缩内边距但文字不换行、不横向溢出 |
| 结果计数 | 字号 12、辅助色，显示在排序行左侧 | 按当前分类、搜索和关注结果动态更新；例如“共 128 件”仅为预览值 |
| 内容卡片 | 圆角 14–16，细描边，极轻阴影 | 卡片点击区域和独立关注操作分开；关注使用爱心图标 |
| 退市遮罩 | 使用完整的土豆团子搭牌沿贴纸插画（含白色贴纸描边、雾蓝绿牌面、岸线与图内手写“已退市”）；整图只加极轻薄雾 | 不用 CSS 灰色矩形或代码文字替代确认稿；团子与牌子按 A 版组合，底图保持辨认度 |
| 底部导航 | 暖白半透明液态玻璃，柔和模糊、细边和轻阴影 | 五项固定顺序：首页、集市、旨意、消息、金库；透镜跟随按压与滑动 |

## 导航插图资源验收

- 每个运行时资源文件只包含一个完整主体，禁止从横向拼图直接切出带相邻图案的切片。
- PNG 必须含透明通道；图案在四边保留约 10% 的透明安全留白，画布边缘不能出现可见像素。
- 同一组图标统一光学尺寸与中心位置；缩放到实际 36 逻辑像素后检查，不能只验收大图。
- 同时在白色、暖灰色与深色检查底上验收透明边缘，并检查静止、按压放大和滑动过程。
- 源图归档到 E 盘资源库，仓库保留打包所需的轻量 PNG。2026-10-15 清理后的旨意、消息、金库图标位于 `assets/navigation/set-c-clean/`。

## 交易集市基线

- 顶部不重复放页面标题；第一行显示浅色成交播报，右侧放大镜展开搜索框。播报不用红底或红色圆点，左右边界与下方内容对齐。
- 第二行把醒目的“土豆王国 / 居民图鉴”分区切换与轻量排序“最热、最新、价格、关注”放在同一行；不再用“全部藏品”作为分区筛选。
- 分区选中态使用浅麦色，分类选中态使用雾霾蓝；分类行保持轻量，不铺整条土豆色底。
- 土豆王国与居民图鉴 PFP 下方显示后台动态分类胶囊；沿用后台名称和顺序。默认选择当前分区中按后台顺序排列的第一个有效分类；切换主分区时选择新分区的第一个有效分类。
- 成交播报点击后打开面板，展示最新 20 笔成交和藏品走势。走势指标为近 1 小时成交、近 24 小时成交、成交均价和当前地板价；成交均价按近 24 小时记录计算，价格图按近 30 日成交均价汇总。
- “最热”继续按现有近 30 天成交规则排序；关注继续使用本地偏好和爱心图标；筛选与排序不改交易记录。
- 走势面板始终显示“分区 → 动态分类 → 藏品名称搜索”控件，候选藏品用可滚动列表选择，避免藏品增多后横向堆叠名称。
- 即使某分区暂无藏品，分区切换和搜索仍保持可见；居民图鉴空态提供返回土豆王国的快捷入口。
- 商品卡片保持正方形图片；在售藏品显示“地板价”，退市藏品显示“退市价”；退市遮罩使用用户确认的土豆团子 A 与雾岛牌 B 组合。
- 列表宽度跟随视口调整：手机双列，平板三列，桌面四列并限制内容最大宽度；列表末项需避开底部导航和设备安全区。
- 页面不把预览占位数据写入产品，也不新增交易或资产变更流程。

## 合成列表基线

- 页面标题为“藏品合成”，居中显示；标题下方用紧凑说明行交代页面用途，不重复放品牌 Logo。
- 使用“进行中 / 未开始 / 已结束”三态筛选，并显示各状态的真实活动数；状态根据活动开始时间、截止时间和剩余额度计算。
- 活动卡保持紧凑：方形目标藏品图、藏品名、起止日期与时刻、合成额度进度和清晰的进入入口。移动端首屏目标是完整展示多个活动卡，列表余项可继续纵向滚动。
- 卡片点击沿用现有合成详情与选材流程；活动中显示“进入合成”，未开始和已结束状态显示对应查看入口。
- 字号沿用页面标题 22/28、卡片标题 15/20、主要控件 14/20、辅助信息 11/14；采用白底、浅奶油卡片与雾霾蓝交互色。
- 真实活动名称、时间、额度与藏品图片均来自后台数据；预览中的示例文案不写入产品数据。

## 合成详情与交互基线

- 详情页顶部仅保留返回键和居中的“合成详情”，不重复放品牌 Logo、通知或头像；页面底部不添加整幅装饰风景。
- 页面保留目标藏品、活动时间、所需材料、材料进度、选材入口和合成入口。选材使用底部抽屉，支持全选、逐件选择、数量反馈和材料不足时前往集市。
- 材料齐备后点击“开始合成”打开确认弹窗；确认后调用现有合成流程，成功时在详情页上显示完成弹窗。确认与完成均不新增独立页面，也不显示顶部步骤条。
- 集市跳转携带缺少的材料名称并展开搜索；返回详情时保留已选材料。合成材料、目标藏品图片继续使用后台 `image_url`，完成弹窗复用目标藏品缩略图与原生图标，不增加独立 ImageGen 素材。
- 页面字号统一使用：页面标题 22/28，区块标题 18/24，藏品名 15/20，正文和主要控件 14/20，关键数量 18/24，辅助信息 11/14；字重和颜色沿用本规范令牌。
- 本次范围只涉及合成详情与缺料跳转所需的集市搜索参数；不调整合成规则、后台字段、交易逻辑、共享导航或其他页面样式。

## 金库确认与实现基线（2026-10-16）

- 以 TREASURY_APPROVED_BASELINE.md 与 E 盘「金库确认稿_移除命运抽签.png」为视觉基准，金库内不再显示命运抽签。
- 纯白底，不显示顶部「金库」标题行；身份区顶部留白16、浅色三列财富摘要、两行四列快捷入口、我的藏品。创世神保留独有控制台入口；极窄屏将该入口移到身份信息下方，避免压缩昵称。
- 「我的藏品」右侧放大镜触控区至少44×44，点击展开本账户持有藏品的名称搜索；输入字号16、正文色与中性细边框，不显示蓝色焦点外框。忽略首尾空格及英文大小写；清空或关闭恢复完整列表。空搜索结果提供清空入口，与空仓库区分。总件数不因搜索变化。
- 五个新图标沿用 A 经典岛居，合成/权益/转赠复用首页素材。空箱沿用 C 绘本彩铅，「去集市」使用 B 彩铅雾蓝底图与独立文字。
- 主要文字采用 MiSans 400/600，不继续使用全页 800/900 字重。原有底栏素材与玻璃交互不在本轮重做。
- 内容最大宽 720；快捷入口固定四列；藏品图保持正方形，手机两列、内容宽度至少 640 时三列。列表尾部留出底栏和设备安全区。
- 数据继续沿用当前账户和现有收益统计口径，不把预览数字写入页面；收益标签仍非净收益核算承诺。
- 请求错误显示重试，不显示假空资产。刷新失败保留上次数据；成功后更新头像、数量和藏品分组。邀请尚无路由，明确提示暂未开放。

## 预览与实施步骤

1. 先根据用户确认的要求做页面预览，检查移动端首屏、长内容、动态分类、空态和底部安全区。
2. 用户确认后实施；只改当前获准页面、已确认的共享导航或规范文件。
3. 实施后运行目标文件 lint、类型检查（如有既有错误需注明）、构建或导出检查，并记录结果。
4. 新页面使用本规范作为字号和布局基准，但颜色、模块和交互仍须各自先预览确认。
