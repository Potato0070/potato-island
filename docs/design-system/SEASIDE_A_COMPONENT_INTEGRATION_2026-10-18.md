# A 系列通用交互组件：首批接入与验证

本文记录发布前的本地验收。本批次只调整前端 UI 和反馈。数据库结构、RPC、计费和交易规则未改动。

## 可复用组件

- `SeasideFrame`：根据已测量的透明边界和安全区显示原始 WebP；九块视口保留边角比例，延展中间纸纹。素材不包含运行时按钮文字。
- `SeasideButton`：蓝色主操作、金色交易、米白次操作、陶土红撤回。最小高度 56，20 像素粗体；禁用和加载状态阻止点击，加载时保留文案布局空间。
- `SeasideTextInput`：16 像素输入文字，暖棕焦点，错误信息与提示在框外独立排版；输入内容明确位于素材上方，避免背景盖住数值。
- `SeasideSurface`：确认弹窗、底部抽屉、提示纸条，按内容布局，不将整张合成预览当作背景。
- `SeasideSheet`：固定标题与提交区，正文可滚动；忙碌时禁止关闭；保留系统安全区和 iOS 键盘避让。
- `TradeConfirmDialog`：共用确认弹窗；忙碌时禁止重复确认与取消，失败保留原内容。窄屏按钮自动纵排。
- `SeasideResultDialog`：共用完成反馈，可附加结果信息和次操作。

素材来自已确认的 `assets/ui-kit/seaside-a-v1/runtime`，首批使用 9 个 WebP。原始 PNG 母版无需进入页面。未新增 IP 插画。

## 已执行的验证

1. 相关 TSX 与常量通过 ESLint；TypeScript 输出在本批路径中无诊断。项目整体仍存在历史类型错误，未宣称全量类型检查通过。
2. Expo Web 静态导出通过；36 页脚本引用检查通过，首页脚本 gzip 521,945 字节，未超过既定 550 KB 检查阈值。
3. 本机隔离服务 `127.0.0.1:8192` 对导出产物中的 Supabase 地址作测试替换；请求进入本地假接口，没有转发真实数据库。
4. 未登录购买进入登录提示，并可跳转登录页。使用纯虚构账号登录本地假接口后继续测试。
5. 我的藏品：输入 301 超过测试限价 300，错误显示在输入框下方；输入 6 后本地模拟上架成功，状态更新；撤回经过确认后显示成功，原寄售价保留为 6。
6. 购买模拟失败：确认弹窗保持打开，显示错误，按钮恢复可操作，没有跳转到成功页面。
7. 独立寄售模拟失败：6.25 金额保留，取消确认后仍可修改。
8. 375 宽抽屉：输入值可见、输入字体 16px、未发现坏图或页面横向溢出。320 宽撤回确认按钮纵排；430 宽购买确认按钮并排，未发现横向溢出。
9. 集市现货模拟购买成功：确认关闭，成功信息显示，已成交项目从列表移除。

请求证据位于本地 `output/seaside-app-check-20261018/requests.jsonl`；服务和测试输出属于本地演示文件，不应作为生产后端发布。

## 边界与后续验收

- 这次验证在桌面浏览器模拟窄屏完成；真实 iOS 键盘、原生 Android/iOS 和低性能设备还需设备验证。
- 没有执行真实购买、扣款、寄售或撤回；未验证资金原子性。旧交易接口的后端约束需要在数据库工作恢复后单独核对。
- 仍沿用现有字体资源；平台字体选型不是本批完成项。
- 后续页面接入时应继续使用这些组件，避免再次分别编写输入框与弹窗的素材定位。
