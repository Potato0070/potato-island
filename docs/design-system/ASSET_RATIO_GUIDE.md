# 土豆岛素材比例与展示规范

状态：跨页面通用规范。新增或替换素材时，先确认画布比例与透明安全区，再确定组件显示方式；不得为了塞进容器而把整张素材横向或纵向压扁。

## 统一规则

| 素材用途 | 画布比例 | 组件显示规则 | 是否允许裁切 |
| --- | --- | --- | --- |
| 藏品、PFP、头像、藏品缩略图 | 1:1 | 外层固定正方形；图片在展示窗内 `contain`，完整保留原图 | 不裁切、不拉伸 |
| 卡框、贴纸、角色和独立插画 | 保留源图比例 | `contain`，由容器适配，不改变素材本身比例 | 默认不裁切 |
| 竖向编号签、状态签 | 约 1:2 | 按源图比例设定宽高；文字作为独立图层叠加 | 不裁切、不拉伸 |
| 横向按钮底图 | 约 3.8:1 | 使用九宫格，只拉伸中间区域；横向边缘按宽度、上下边缘按高度等比缩放 | 不裁切 |
| 有装饰边框的纸面、确认框和结果卡 | 按源图设计稿 | 使用九宫格保持四角和边框厚度；内容区域由布局承载 | 不裁切 |
| 撕纸边缘底纸 | 1:1 | 九宫格保留撕纸边缘；边缘缩放分别按容器宽、高计算 | 不裁切边缘，不拉伸整张纸 |
| 空状态插画 | 保留源图比例 | 使用 `contain`；容器尺寸按画布比例设定 | 不裁切 |

## 组件责任

- `FolioArtwork` 固定 1:1；图片统一使用 `contain` 完整显示。我的藏品主轮播和详情主卡启用 F 确认稿中的叠纸卡框，藏品图只在卡框透明窗口内显示；主轮播图片可在窗口安全范围内轻微倾斜。卡框外层与透明窗口都必须保持透明，只有缺失图片的 fallback 可以使用米色底，不能用米色底填满卡框透明区域。胶片缩略图、弹窗小图和转赠选择小图使用 `framed={false}`。
- `FolioSerialTag` 与 `FolioStateTag` 统一使用接近原图的 1:2 画布；编号和状态文字不烘焙进标签图片。
- `FolioButton` 使用九宫格按钮底图；可变长文案只改变中间宽度，不挤压手绘边角。
- `FolioPaperSurface` 的纸面、铭牌、确认和结果素材使用九宫格；横向、纵向边缘按容器宽高分别缩放。
- 九宫格切片不得穿过素材上的折角或纸张叠层；改变容器比例时，优先保留装饰边缘，不得让边角进入可拉伸的中心区域。
- `paper-texture.webp` 是带撕纸外沿的整张方纸，不是无缝纹理；不用于横向信息行、窄按钮或宽卡片背景。宽信息容器使用规整的浅纸色面板，避免撕边被横向拉伸。
- 编号签和状态签必须完整留在卡框边界内；动态文字按变换后的可视范围在标签内居中，不能压住藏品图或伸出卡片。
- 空状态、成功反馈和 Tudooo 插画使用 `contain`。如果素材在容器里显得过小，应调整容器，而不是改变原图比例。

## 当前页面的修正规则

- 我的藏品主轮播使用 F 五屏确认稿的叠纸相框素材，图片必须对准透明窗口，保持完整并以轻微倾角展示；在框的下沿显示编号，页码、蓝点和缩略胶片按确认稿顺序排列，缩略胶片下方显示在库/寄售状态。
- 详情页主卡同样使用完整叠纸相框，并在右侧预留的纸边上显示编号签和状态签；纸面、卡框和签贴必须分别显示，不得互相覆盖或裁切。
- 我的藏品轮播视口一次只展示一张主卡，不露出相邻卡片的叠纸装饰；最多 8 个分页点随当前藏品逐张移动，页码文字显示总列表中的准确位置，当前缩略胶片随主卡居中。
- 编号签和状态签必须放在对应卡片或纸面组件的裁切范围内。详情页的签贴在纸面内部，不能挂在纸面外侧。
- 搜索输入字号至少 16 px，避免移动浏览器聚焦时自动缩放；Web 输入框去除浏览器默认蓝色外框，保留容器自己的细纸色边线。
- 输入框边框由外层纸色容器绘制；输入控件自身不绘制浏览器焦点外框，输入、说明文字和操作按钮都必须落在素材内边距以内。
- 获取时间排序按藏品进入当前金库的最新转入记录排序；无转入记录时回退到藏品生成时间。时间记录只在用户选择该排序时读取，避免拖慢页面初次打开。

## 新素材交付要求

1. 生成前确定用途、目标画布比例、透明背景需求和安全留白。
2. 状态贴纸、图标、角色等独立素材保留完整透明边界，不把动态文案、价格或编号烘焙进图。
3. 带边框的可变尺寸素材要在源图中预留九宫格安全区；装饰不能进入可拉伸的中心切片。
4. 导出后记录像素尺寸、宽高比、透明边界和实际组件显示规则，再纳入代码。
5. 未经用户确认，不把候选图替换进运行时资源库。
